## 实施范围与顺序

- [x] 扩展 `zcode_remote_read`：返回可跨调用/网关重启使用的消息游标；以消息 ID、已读字符偏移和前缀摘要续读。每页正文仍有上限，但返回 `hasMore`，不丢弃超长消息剩余内容。游标绑定任务/工作区；错误游标拒绝，锚点消失明确报告历史缺口。

- [x] 扩展 `zcode_remote_wait` 的显式消息模式，沿用同一分页结果；新消息或状态变化即可返回。默认状态模式保持兼容。轮询间释放连接，空轮询不重放已读正文，不把超时推断为中断。
- [x] `zcode_remote_send` 先捕获消息基线，返回该游标及原生请求 ID；随后通过 read/wait 得到本次发送后的内容。仅在用户消息 ID 与原生 `turnIndex` 能精确对应时声明回复关联，否则明确未确认。ACK、观察到消息、回合结束、业务验收分别表达；不强制注入模型回执提示词。
